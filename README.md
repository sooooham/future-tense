# Future: Tense

*One year in Paldi, Ahmedabad, 2070.*

A scroll-driven interactive story. Carbon is the currency. Six climate crises arrive two months apart — employment, water, food, flood, health, and a state repopulation programme. At each checkpoint you choose how to survive; every choice spends Carbon Credit Points and moves four meters: Privilege, Ethics, Personal Welfare and Community Welfare. At the end, the city prints your year as a receipt — and tells you who paid for it.

**Designed by Soham Sharma · Coded in collaboration with Claude Code**

Built with plain HTML, CSS and JavaScript. Sound is generated live with Web Audio.

## Run it locally

```
npx serve .
```
or open the folder in VS Code and use the Live Server extension. (Opening `index.html` directly from the file system also mostly works, but a local server is closer to the real thing.)

## Where things are

| File | What it does |
|---|---|
| `js/story.js` | All the writing: captions, choices, prices, meter effects, callbacks, verdicts |
| `js/engine.js` | Scroll camera, worlds and transitions, checkpoints, wallet and meters |
| `js/ending.js` | The receipt, its decoding, the verdict |
| `js/audio.js` | Generated sound |
| `css/style.css` | The visual system |
| `assets/` | Skies and grounds (images), buildings and people (SVG) |
| `HANDOFF.md` | Full spec and build status |
